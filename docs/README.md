# omapom — Pomodoro timer for Omarchy (Documentation)

This directory contains project documentation.

## Screenshots

- [Bar widget with settings popup](widget_screenshot.png)

## Widget reference

The pomodoro widget appears in the Omarchy status bar and provides:

- **Left-click**: Start / pause the timer
- **Middle-click**: Skip to the next phase
- **Right-click**: Open the settings popup (shown in the screenshot above)

See the main [README](../README.md) for installation and usage instructions.
